# Agentic Legibility

This project is intended to showcase exploratory work on serialising public sector workflows (especially those accessible through [gov.uk]())
so that they can be interpreted and executed by agents.

The local GOV.UK Forms → SFSM adapter, batch compiler and no-agent web preview are
documented in [durable_poc/forms_adapter/README.md](durable_poc/forms_adapter/README.md).
